# Development Style

This file will evolve as the project develops.

## General

- Prefer simple, readable code.
- Avoid unnecessary abstraction.
- Keep components focused.
- Use descriptive names.
- Avoid unnecessary dependencies.
- Build features incrementally.
- Do not refactor unrelated working code.

## Frontend

- Use TypeScript.
- Use reusable components where it makes sense.
- Keep API logic outside UI components.
- Design responsively from the start.
- Prefer clean, spacious layouts.
- Avoid generic-looking admin dashboard design.

## Backend

- Keep routes simple.
- Put business logic in services where appropriate.
- Keep database models separate from API schemas.

## Development approach

- Make the smallest change required for each task.
- Test after meaningful changes.
- Avoid changing unrelated files.
